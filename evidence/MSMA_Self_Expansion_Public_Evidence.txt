============================================================

This document intentionally omits or abstracts:

- local username and machine name
- absolute filesystem paths
- process identifiers
- Python object memory addresses
- registry object addresses
- unique UUID-style mission/route/trace/manifest/capability IDs
- complete internal payload structures
- detailed agent specifications
- full runtime contracts
- internal adapter implementation
- internal orchestration logic
- detailed rollback implementation
- timestamps not required for verification
- duplicated debug output

The purpose is to expose enough observable evidence to verify the
Self Expansion result without unnecessarily disclosing MSMA's internal
implementation details.
